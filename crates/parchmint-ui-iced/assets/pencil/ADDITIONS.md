# Corrected ParchMint pencil SVG additions

This pack contains the corrected versions of the additional icons, rebuilt entirely from the latest corrected icon sheet.

Corrected icons include:
- previous-match = simple up arrow
- next-match = simple down arrow
- whole-words = bracketed ABC
- exit-focus = four inward-pointing arrows
- sidebar-toggle = chosen explorer/sidebar icon

All icons are individual SVG files in `icons/`. Matching PNG crops are in `source-png/`.
