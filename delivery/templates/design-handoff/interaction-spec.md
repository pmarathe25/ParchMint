# Interaction Specification

For each interaction, record requirement IDs, screen/component IDs, trigger, preconditions, state transition, focus/selection behavior, keyboard equivalent, error/cancel behavior, reduced-motion behavior, and resulting persistent or view-local state.

Cover editor/pane focus, drag/drop, comments, local/global search and replacement, spellcheck, Appearance, disclosure, dialogs, save/recovery, History restore, Recently Deleted, and export.
