# Reference Fixtures

Define every `fixture_id` used by `screen-inventory.csv`.

For each fixture record:

- Stable fixture ID and purpose.
- Project hierarchy, document content, metadata, comments, and search/history state.
- Active destination, pane, tab, document, selection, focus, scroll, and disclosure state.
- Window dimensions, scale, platform assumptions, and reduced-motion setting.
- Any intentionally variable native rendering.

Fixture definitions describe reproducible state, not historical design rationale.
