# Search and replace

- Search matches highlight the matching text itself rather than a containing card.
- Global Search remains in the left pane and has an explicit return to Explorer.
  Use a query plus case-sensitive and whole-word icon toggles. An optional
  replacement field starts replacement review. Group results by document and
  show inline prefix, highlight, and suffix so the highlight does not cover
  adjacent text. Activating a result focuses the matching editor view, scrolls
  to it, and highlights it. Whole-project Replace Preview fills the middle pane
  while Search stays left and Inspector stays right; it is not a modal or card.
  Its hierarchy supports selected, unselected, and indeterminate parent states.
  Do not show a scope selector.
