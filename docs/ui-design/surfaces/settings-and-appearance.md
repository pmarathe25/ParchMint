# Settings and appearance

- Settings uses the full main pane with list/detail editors. Appearance provides
  exactly System, Light, and Dark, with reference states for operating-system
  changes and explicit overrides. Custom style rows end with a trash action;
  reserved style rows put `Reserved` in the same column and have no trash
  action. Metadata rows have a drag handle and trailing trash action, and their
  order is their display order.
