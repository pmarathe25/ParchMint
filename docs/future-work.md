# Future work

**Selection rule:** Revisit an idea when a writing task justifies it. Keep the UI
minimal, reveal detail when needed, and remove completed items from this list.

- **Navigation:** Quick Open, a small command palette, Explorer filtering, and a
  document outline; Back/Forward through writing locations.
- **Writing sessions:** Optional return notes and session summaries without
  productivity scoring.
- **Access:** Keyboard operation of all dropdowns, screen-reader checks on each
  platform, and comment markers with Inspector hidden.
- **Import and Research:** Text, Markdown, HTML, and DOCX import; attachments and
  previews.
- **Editing and review:** Footnotes, tables, media, track changes, comment search,
  and review exchange before live collaboration.
- **Language:** Scoped/regex search, more dictionaries, mixed-language text, CJK
  input, bidirectional editing, and optional grammar assistance.
- **Export:** Presets, partial export, contents and front matter, ebook and print
  formats.
- **History:** Partial restore, remote backup, integrity tools, and retention rules.
- **Workspace:** Saved arrangements, richer planning views, themes, density, and
  settings search when the settings inventory warrants it.
- **Distribution:** More architectures, signing, notarization, and automatic updates.
- **Motion:** Short overlay fades that respect reduced motion and never delay input.

**Constraints:** Keep authored data open and deterministic. Imports and generated
edits use the command, undo, save, recovery, and History paths; caches remain
rebuildable. New services need explicit privacy and offline behavior. Add
migrations only for a supported use; backwards compatibility is not required.
Mobile, web, and AI assistance need separate product decisions.
