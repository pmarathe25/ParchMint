# Platform scope

- **PLAT-001:** Windows, macOS, and Linux are first-class v1 targets. Working on only one platform does not complete a capability.
- **PLAT-002:** ParchMint must install and run as a desktop application using native windows, menus, dialogs, clipboard integration, and platform conventions.
- **PLAT-003:** All three platforms must use the same project format, domain model, feature set, and compatibility rules. Platform conventions may differ without changing authored data.
- **PLAT-004:** Mobile and browser-only clients are out of scope.
- **PLAT-005:** Exact minimum operating-system and Linux-distribution versions must be frozen before public beta, based on native CI and runtime validation rather than framework documentation alone.
