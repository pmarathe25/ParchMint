# Desktop interaction quality

- **A11Y-001:** All primary workflows are usable with the keyboard.
- **A11Y-002:** Focus is visible.
- **A11Y-004:** Focused, selected, disabled, warning, error, comment, search-match, and save states use a non-color cue as well as color where useful.
- **A11Y-005:** UI works at 100%, intermediate scaling, and 200% without caret, selection, hit-test, or layout drift.
- **A11Y-006:** The editor stores text as UTF-8 and preserves ordinary English keyboard input and literal tabs. Combining characters, emoji, and other text remain valid stored data, but international-language editing is not a v1 acceptance target. CJK IME, bidirectional editing, Arabic editing, and multilingual acceptance testing are deferred.
- **A11Y-009:** Light and Dark appearances meet applicable text, icon, focus, selection, and state contrast requirements.
- **A11Y-010:** Normal clipboard copy, cut, paste, and sanitized rich-text paste work on all supported platforms.
